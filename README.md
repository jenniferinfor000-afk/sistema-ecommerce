Sistema de E-commerce

 Descrição do Minimundo

O projeto consiste na modelagem conceitual de um banco de dados para um sistema de e-commerce. O sistema tem como objetivo organizar as informações de clientes, produtos, categorias, pedidos e pagamentos realizados em uma loja virtual.

O sistema permitirá o cadastro de clientes, o gerenciamento dos produtos disponíveis para venda, a organização dos produtos em categorias, o registro dos pedidos realizados pelos clientes e o controle dos pagamentos relacionados aos pedidos.

 Problema do Mundo Real

Uma loja virtual precisa organizar uma grande quantidade de informações relacionadas aos seus clientes, produtos e vendas. Sem um banco de dados estruturado, pode ser difícil controlar os produtos disponíveis, identificar quais produtos fazem parte de cada pedido, acompanhar os pagamentos e manter os dados dos clientes organizados.

O sistema de e-commerce busca solucionar esse problema centralizando as informações em um banco de dados organizado, facilitando o gerenciamento dos produtos, clientes, pedidos e pagamentos.

 Regras de Negócio

1. Um cliente pode realizar vários pedidos.
2. Cada pedido pertence a apenas um cliente.
3. Um pedido deve possuir pelo menos um item.
4. Um pedido pode possuir vários itens.
5. Um produto pode aparecer em vários pedidos.
6. Cada item de pedido está relacionado a apenas um produto.
7. Cada produto pertence a uma categoria.
8. Uma categoria pode possuir vários produtos.
9. Cada pedido possui um pagamento associado.
10. Um pagamento pertence a apenas um pedido.
11. Cada produto possui um preço e uma quantidade disponível em estoque.
12. O sistema deve armazenar a data em que cada pedido foi realizado.
13. O sistema deve armazenar o status do pedido para permitir o acompanhamento da compra.

Principais Processos do Sistema

* Cadastro de clientes.
* Cadastro e gerenciamento de produtos.
* Organização dos produtos por categorias.
* Criação de pedidos.
* Inclusão de produtos nos pedidos.
* Registro dos pagamentos.
* Acompanhamento do status dos pedidos.
* Consulta das informações dos produtos e clientes.

 Objetivo

O objetivo do projeto é representar, por meio de um Modelo Entidade e Relacionamento (MER), as principais informações e relações necessárias para o funcionamento de um sistema de e-commerce.
